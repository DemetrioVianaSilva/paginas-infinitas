Páginas Infinitas — Admin Panel

Como usar:

- Abra `admin/index.html` no seu navegador para gerenciar livros localmente.
- Adicione/edite/exclua livros no painel; os dados ficam salvos em `localStorage`.
- Vá em "Exportar JSON" e clique em "📋 Copiar JSON" para copiar o conteúdo de `data/books.json`.
- Cole o JSON no arquivo `data/books.json` no seu repositório e faça commit para atualizar o site.

Dicas:
- Para testar o site localmente, use um servidor simples (por exemplo, `npx http-server` ou `python -m http.server`) a partir da pasta do projeto.
- O arquivo inicial `data/books.json` vem vazio; o painel não tem livros pré-carregados.
